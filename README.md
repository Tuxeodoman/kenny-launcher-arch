# Kenny Launcher для Arch Linux

Готовый пакет **9.6.1-dev** для **Arch Linux x86_64** и совместимых систем. Qt и Java 8/17/21/25 включены. Нужно около 3 ГБ свободного места без учёта Minecraft.

Установка из терминала обычного пользователя:

```bash
curl -fLO https://github.com/Tuxeodoman/kenny-launcher-arch/releases/download/v9.6.1-dev-arch/install.sh
bash install.sh
```

Откройте **Kenny Launcher Dev** в меню или выполните `~/.local/bin/kenny-launcher-arch`.
Войдите в свой аккаунт и скачайте сборку. Установщик запросит пароль для установки зависимостей через pacman. Лаунчер запускайте без sudo.

Для Ubuntu: https://github.com/Tuxeodoman/kenny-launcher-ubuntu
Для NixOS: https://github.com/Tuxeodoman/kenny-launcher-nixos

Обновление: закройте лаунчер и снова выполните установщик из нового релиза этого репозитория. Сборки и аккаунт сохраняются.
